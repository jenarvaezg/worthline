# The shared AI baseline is rate-limited

The free shared assistant baseline backed by a provider key such as `GROQ_API_KEY` is rate-limited from the first slice. Hosted usage is limited per user or workspace when authenticated, and by a coarser fallback such as IP when no user is available; local usage can remain effectively unmetered because the developer controls the environment.

This treats the shared key as a bounded product resource, not infrastructure magic. The limit can be simple at first, but every request path using the shared key should pass through it before calling the provider. On serverless the counter cannot live in process memory across invocations; reuse the existing control-plane database as the shared store rather than adding new infrastructure. The Vercel AI Gateway spend ceiling (ADR 0050) is a coarse backstop, not a substitute for this per-user limit.

**Every request path means every model, not only the conversational one (#1258).** The eager attachment extractors (ADR 0063) call a paid provider *before* the chat turn, on a key of their own, and for a while they passed through no counter at all: the chat rate limit meters requests to the route rather than calls to a model, the AI token meter reads a total the extractor contract never returns, and `demo` resolves to `premium`, so an anonymous visitor reached the vision model with no plan gate. A path that spends money and that no counter can see is the failure mode this decision exists to prevent, whatever the amount.

The fix stays inside this decision rather than inventing another mechanism: the extractor gets its own control-plane counter, per workspace and per IP for demo, plus a shared global daily fuse, checked before the reading and recorded after it. Its unit is **calls, not tokens** — the honest unit for a seam whose contract returns validated JSON and never provider usage — and it is deliberately a *separate* counter from the token meter, so «the recurring cost of a conversation» and «the one-shot cost of ingesting a document» stay two readable numbers. Routing the extractor through the Gateway (ADR 0050) would add a money ceiling underneath all of this and remains worth doing; it does not replace the per-caller brake, for the same reason the Gateway ceiling never replaced the chat rate limit.
